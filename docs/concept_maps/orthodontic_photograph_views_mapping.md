# Orthodontic Photograph Views ConceptMap Mappings

This document enumerates the curated mappings used by
`terminology/resources/concept_maps/orthodontic_photograph_views.py`.

Notes:
- Source (primary): Open Ortho photographic view codes.
- Target: SNOMED CT photographic concepts (descendants of 723394009).
- Only direct 1:1 matches are included.
- Extraoral 3D and Intraoral 3D groups remain empty placeholders.
